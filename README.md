### 🎓 [campus-volunteer](https://github.com/Eleanorchennnnnn/campus-volunteer) · 高校活动报名与志愿平台

Spring Boot + Redis + Vue3 全栈实战，由 Redis 经典实战项目重构而来：

- 🛡️ 针对缓存穿透、击穿、雪崩的完整防护方案，保障活动详情页稳定可用
- ⚡ Lua 脚本原子校验并扣减报名名额，配合数据库事务与失败补偿，5 并发抢 3 名额**零超卖**
- 📅 BitMap 实现活动签到，ZSet 构建志愿时长排行榜，形成「报名 → 签到 → 时长 → 证明」完整闭环
- ❤️ Set 结构实现一人一赞与组织关注

### 🌍 [geo-core-analysis](https://github.com/Eleanorchennnnnn/geo-core-analysis) 海底地质岩心图文分析系统

Java Servlet + MySQL 构建，用于石油地质教学与科研的岩心图像智能分析：

孔洞分析：Otsu 阈值分割 + 连通区域检测，统计面孔率
裂缝分析：Canny 边缘检测 + 霍夫变换，提取裂缝长度、方向与分形维数
粒度分析：颗粒分割与统计，输出中值、均值、分选系数、偏态、峰度
三级角色权限（普通用户 / 教师 / 管理员），岩心图文数据一体化管理
